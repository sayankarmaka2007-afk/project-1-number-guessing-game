# project-1-number-guessing-game
A simple and interactive Number Guessing Game built with Python. The program randomly generates a secret number between 1 and 100, and the player has to guess the correct number within a limited number of attempts. After each guess, the program gives feedback to help the player know whether the guess is too high or too low. The game also keeps track of the number of attempts and ends when the player guesses the correct number or exceeds the allowed attempts.

Concepts used:

1. Python random module
2. While loops
3. if-elif-else conditions
4. User input and type conversion
5. Variables and counters
6. Basic game logic
